# FrictionHub

---
FrictionHub is a small collection of Quality of Life improving miniweb tools made with html css and js only.


## Features

- CopyBoard
Here you can save frequently used texts emails etc inside your browser storage
- Password Generator 
You can save 100% secure and random passwords. and save it in your browser storage. so if you forgot it you can retrive it again.
- Text Cleaner
You can clean a large messy text by removing empty lines. unwanted spaces and more.
- Case Conveter 
Convert a large text into different cases like uppercase lowercase sentnce case etc...
- Shopping List
Create and manage shopping lists and save them as PDF files.
- Color converter
For html coders converting color codes are difficult.
- Find and replace
Finding and replacing some texts from long paragraphs areuch boring stuff.
- Currency converter
Buying items with international cards are very hard to find exhchange rates and converting
- qr code generator
instead of sending urls using url we can enter sites using scanning.
- text difference finder
finding small small differences in texts paragraphs are very boring
- url cleaner
remove tracking ids and unwanted things from url.
- Weather dashboard
find the weather of a city by searching simply.
